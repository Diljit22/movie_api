# Movie API

This application serves as an API layer for a movie browsing application, providing endpoints for fetching trending movies, viewing movie details, and managing a persistent list of user favorites.

## Features

- **Persistent Favorites:** Full CRUD functionality for a user's favorite movies, saved locally.
- **Performance Caching:** API responses for movie data are cached locally to minimize network calls and improve response times.
- **Asynchronous**: Performant non-blocking API calls done via Python's async/await.
- **Test Suite:** Includes both unit and integration tests with 88% code coverage.

## Tech Stack

- **Backend:** Python 3.13
- **Framework:** FastAPI
- **Data Validation & Settings:** Pydantic
- **HTTP Client:** HTTPX
- **Testing:** Pytest, Pytest-Asyncio, Pytest-HTTPX
- **Linting & Formatting:** Ruff
- **Type Checking:** MyPy

## Setup and Installation

### Configure Environment Variables

Create a `.env` file in the root directory with your TMDB API key:

  ```bash
  # .env file
  TMDB_API_KEY="your_secret_tmdb_api_key_goes_here"
  ```

Other configurable elements include:

- `tmdb_image_base_url`
- `cache_duration_hours`
- `cache_filepath`
- `favorites_filepath`

### Install Dependencies

Set up a virtual environment and install dependencies:

  ```bash
  # Install the application
  pip install .

  # Or, install in "editable" mode with development tools
  pip install -e .[dev]
  ```

**Note:** Use `pip install -e .[dev]` if you plan to run tests or use development tools (linting, type checking). The basic `pip install .` is sufficient for running the application.

### Start the Server

With the virtual environment activated and dependencies installed, start the Uvicorn server:

  ```bash
  uvicorn movie_api.main:app --reload
  ```

The API will be available at `http://127.0.0.1:8000`.

## API Documentation

Once the server is running, visit the interactive API documentation at `http://127.0.0.1:8000/docs` for easy exploration and testing of all endpoints.

## Testing

Tests are run via Pytest and coverage reports are generated by default:

```bash
# Requires installation with dev dependencies
pytest
```

Tests use mocking to isolate the application from the live TMDB API, ensuring reliability and reducing API calls.

## Data Storage

- **Cache:** Movie data from TMDB is cached in `.data/cache.json` (configurable via `CACHE_FILEPATH`)
- **Favorites:** User favorites are persisted in `.data/favorites.json` (configurable via `FAVORITES_FILEPATH`)
